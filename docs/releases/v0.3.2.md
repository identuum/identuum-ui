# identuum-ui v0.3.2 — release notes

Tag: `v0.3.2` on `main`. The tag push runs `publish-ui-export.yml`, which
publishes the static export as release assets. No container image is
published for this release.

## Why this release

identuum-idp-oss `v0.6.2` embeds this release's export. The pages now follow
what the IdP says it can do: the mail pages appear only where mail can be
delivered, and identuum-idp-ce's admin reset link and approval posture are
honoured. Delta `v0.3.1..HEAD`: 11 commits (measured at `6362206`) and the
release commit.

## What ships

- **Release assets** (`publish-ui-export.yml`, node 26.8.1, pnpm 11.3.0):
  - `identuum-ui-export-v0.3.2.tar.gz` — the export, a deterministic tar;
  - `identuum-ui-export-v0.3.2.json` — the `identuum-ui-vendor.v1`
    manifest: ui commit, lockfile sha256, node and pnpm versions, every
    file's sha256 and the tree digest;
  - `identuum-ui-export-v0.3.2.spdx.json` — an SPDX SBOM of the source;
  - a GitHub build-provenance attestation over the three
    (`gh attestation verify <file> -R identuum/identuum-ui`).

  The tree digest equals the manifest identuum-idp-oss `v0.6.2` embeds.

## Behaviour changes in the shared pages

- **Without mail** (`capabilities.mail_ceremonies` false: identuum-idp-ce,
  or identuum-idp-oss with no SMTP host and sender):
  - the sign-in form shows "Ask your administrator to reset your password."
    instead of "Forgot password?";
  - `/forgot-password`, `/reset-password`, `/verify-email` and `/activate`
    say "not available on this installation" and make no call.

  With SMTP configured, or with an IdP that does not report the key, the
  pages are unchanged.
- The forgot-password form reports "sent" only when the IdP answered 2xx.
- Where `capabilities.admin_reset_link` is true (identuum-idp-ce), the
  org_admin's user detail page offers "Create password reset link": the
  link is shown once, and `/reset-link` redeems it.
- Where `capabilities.user_approval` is false (identuum-idp-ce), Approve is
  hidden. identuum-idp-oss `v0.6.2` declares it true.

## Operator notes

- Nothing to deploy from this repository: the UI arrives inside the
  identuum-idp-oss `v0.6.2` binary.
- An identuum-idp-oss operator who relies on the reset, verification or
  activation mails must configure SMTP (`IDENTUUM_IDP_SMTP_HOST` and a
  sender). Without it those pages now say they are not available, instead
  of offering a form whose mail could not be delivered.
- Verification at the release commit: `make verify` on `main` — see the
  release commit's report for the per-target record.
