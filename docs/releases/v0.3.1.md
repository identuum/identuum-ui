# identuum-ui v0.3.1 — release notes

Tag: `v0.3.1` on `main`. The tag push runs `publish-ui-export.yml`, which
publishes the static export as release assets. No container image is
published for this release.

## Why this release

identuum-idp-oss `v0.6.1` embeds this release's export. It carries the
fixes found since `v0.3.0` in account settings, sign-out and the date
display. Delta `v0.3.0..HEAD`: 17 commits (measured at `cf6575a`) and the
release commit.

## What ships

- **Release assets** (`publish-ui-export.yml`, node 26.8.1, pnpm 11.3.0):
  - `identuum-ui-export-v0.3.1.tar.gz` — the export, a deterministic tar;
  - `identuum-ui-export-v0.3.1.json` — the `identuum-ui-vendor.v1`
    manifest: ui commit, lockfile sha256, node and pnpm versions, every
    file's sha256 and the tree digest;
  - `identuum-ui-export-v0.3.1.spdx.json` — an SPDX SBOM of the source;
  - a GitHub build-provenance attestation over the three
    (`gh attestation verify <file> -R identuum/identuum-ui`).

  The tree digest equals the manifest identuum-idp-oss `v0.6.1` embeds.

## Behaviour changes in the shared pages

- Every date shown is formatted in the browser's zone with the zone named,
  and the exact UTC ISO appears on hover (U-020). Dates the UI sends stay
  UTC ISO.
- `/logout` is a page whose form posts the sign-out; opening it never
  signs out.
- A cookie-session sign-out answered 2xx `{"logged_out":true}` is reported
  as signed out.
- Account settings: the profile tab shows the stored profile (it showed
  empty fields, and saving cleared them); a site_admin's sessions tab
  shows the administrator notice instead of a load failure; revoking a
  session uses `POST /api/v1/revoke` on every edition.
- Surfaces no edition serves are removed: the report export link, the
  org-admin webhooks list and passkey renaming. Removing a passkey is
  unchanged.
- When the IdP is in upgrade mode, the export routes to `/upgrade` instead
  of the unavailable page.
- `/claim` sends `Referrer-Policy: no-referrer`.

## Operator notes

- Nothing to deploy from this repository: the UI arrives inside the
  identuum-idp-oss `v0.6.1` binary.
- Verification at the release commit: `make verify` on `main` — see the
  release commit's report for the per-target record.
