# identuum-ui v0.2.0 — release notes

Proposed tag: `v0.2.0` on `main`. **The owner pushes and publishes; nothing
in the repository performs either.** Publish via the manual
`publish-image.yml` workflow with `version_tag: v0.2.0` (the workflow also
pushes a `sha-<short>` tag). A local annotated `v0.2.0` git tag exists so the
release commit is pinned; pushing it is an owner step.

## Why this release

The published `v0.1.0` image (2026-06-13, commit `5158f0b`) is 64 commits
behind and predates the UI's move to the released OSS backend contract. This
release is the first image that speaks that contract end to end — bearer BFF
transport, released-shape readers, tri-state admin state, edition
boundaries, audit details, honest health — and it ships hardened:
Next.js 16.2.11 (closes an authentication bypass, CVE-2026-64642, plus
SSRF/DoS advisories), sharp 0.35.0, and a runtime stage with npm/npx/corepack
removed (7 HIGH/CRITICAL findings lived in npm's vendored modules; the
standalone runner never executes npm). Scan with the publish-gate shape
(`trivy image --severity HIGH,CRITICAL --ignore-unfixed --exit-code 1`):
exit 0, zero findings.

See `CHANGELOG.md` `v0.2.0` for the full list.
