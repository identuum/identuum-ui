# identuum-ui v0.6.2 — release notes

Tag: `v0.6.2` on `main`. The tag push runs `publish-ui-export.yml`, which
publishes the static export as release assets. No container image is
published for this release.

## Why this release

identuum-idp-oss `v0.9.2` embeds this release's export: /platform-status
names the commit the IdP serves. Delta `v0.6.1..HEAD`: 3 commits (measured
at `99d5c9a`) and the release commit. A patch release: nothing removed or
renamed.

## What ships

- **Release assets** (`publish-ui-export.yml`):
  - `identuum-ui-export-v0.6.2.tar.gz` — the export, a deterministic tar;
  - `identuum-ui-export-v0.6.2.json` — the `identuum-ui-vendor.v1`
    manifest: ui commit, lockfile sha256, node and pnpm versions, every
    file's sha256 and the tree digest;
  - `identuum-ui-export-v0.6.2.spdx.json` — an SPDX SBOM of what ships (the
    production dependency closure `make export-sbom` writes, the file
    `make sbom-scan` judges);
  - a GitHub build-provenance attestation over the three
    (`gh attestation verify <file> -R identuum/identuum-ui`).

  The tree digest equals the manifest identuum-idp-oss `v0.9.2` embeds.

## Changed

- **/platform-status shows the commit.** The IdP's version is followed by
  the commit it serves, read from the public `/system/info` `build_commit`:
  "0.9.2 (commit <short>)". An IdP that serves no commit, answers an error
  or cannot be reached shows the version alone, as before.

## Dependencies

- None changed. next stays at 16.3.8, the latest stable release.

## Known limitations

- None new.

## Operator notes

- Nothing to deploy from this repository: the UI arrives inside the
  identuum-idp-oss `v0.9.2` binary and image.
- Verification at the release commit: `make verify` on `main`.
