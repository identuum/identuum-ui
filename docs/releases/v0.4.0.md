# identuum-ui v0.4.0 — release notes

Tag: `v0.4.0` on `main`. The tag push runs `publish-ui-export.yml`, which
publishes the static export as release assets. No container image is
published for this release.

## Why this release

identuum-idp-oss `v0.7.0` embeds this release's export. An organization
admin can invite users without mail, and a site admin can re-issue a lost
activation link from the organization's page: every one-time link is shown
once to hand over, and mailed only when email delivery is configured (owner
ruling D-016). Delta `v0.3.3..HEAD`: 37 commits (measured at `da8f70b`) and
the release commit.

## What ships

- **Release assets** (`publish-ui-export.yml`):
  - `identuum-ui-export-v0.4.0.tar.gz` — the export, a deterministic tar;
  - `identuum-ui-export-v0.4.0.json` — the `identuum-ui-vendor.v1`
    manifest: ui commit, lockfile sha256, node and pnpm versions, every
    file's sha256 and the tree digest;
  - `identuum-ui-export-v0.4.0.spdx.json` — an SPDX SBOM of the source;
  - a GitHub build-provenance attestation over the three
    (`gh attestation verify <file> -R identuum/identuum-ui`).

  The tree digest equals the manifest identuum-idp-oss `v0.7.0` embeds.

## Behaviour changes in the shared pages

- **Users → Invite user**, where the IdP declares `capabilities.user_invite`
  (identuum-idp-oss `v0.7.0`): creates a pending user and shows the invite
  link, its token and expiry once. The public `/invite` page redeems it.
- **Organization page, "Re-issue activation link"**, for an organization
  whose administrator has not activated yet: retires the earlier link and
  shows the new one once.
- **`/activate`** is offered where the IdP can mail or declares
  `capabilities.activation_link`.
- Copy on the new-organization form, assign-admin, `/activate` and `/claim`
  follows D-016. Reactivate explains `409 activation_pending`.
- A deleted organization's row links only to Restore.
- org-admin audit surfaces follow `capabilities.org_audit`.

## Operator notes

- Nothing to deploy from this repository: the UI arrives inside the
  identuum-idp-oss `v0.7.0` binary and image.
- Verification at the release commit: `make verify` on `main`; see the
  release commit's report for the per-target record.
