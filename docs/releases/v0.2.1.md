# identuum-ui v0.2.1 — release notes

Proposed tag: `v0.2.1` on `main`. **The owner tags and publishes; nothing in
the repository performs either.** Publish via the manual `publish-image.yml`
workflow with `version_tag: v0.2.1` (the workflow also pushes a
`sha-<short>` tag).

## Why this release

The identuum-idp-oss `v0.5.0` compose pins `identuum-ui:v0.2.0`, whose
runtime base carried 11 grype matches, 5 severe. This release moves the
runtime stage to a patched base and keeps local environment files out of
the build context.

- **Runtime base** — `cgr.dev/chainguard/node` pinned by digest
  `sha256:1f903d44fc11a6f6e74447fc2c6a3c141f112217576be5d96c283210116b5d25`
  (image created 2026-09-17), node **v26.9.0** measured in the built image.
  zlib moves to `1.3.2.1_rc20260601-r0` and node-gyp to `13.0.2-r1`; the
  previous base's fixable findings are gone. glibc (Wolfi), not Alpine.
- **Scan, measured on the image built from this Dockerfile**:
  `make grype-scan` (grype 0.119.0 through lictor v0.4.2) — `matches=1
  fixable=0 allowlisted=0 unfixable=1 severe=0`. The match: CVE-2026-89092,
  Medium, glibc 2.44-r6, fix state `unknown`; not suppressed, not claimed
  fixed. Publish-gate shape `trivy image --severity HIGH,CRITICAL
  --ignore-unfixed --exit-code 1`: exit 0, zero findings.
- **`.env` exclusion** — `.dockerignore` excludes `.env*`, `*.env` and
  `*.env.*` at any depth, so no local environment file reaches the build
  context or its cache.

Not itemized here: the 185 non-record commits since `v0.2.0` (294 in all;
see `CHANGELOG.md` `v0.2.1` for the count and its predicate). The image
built for this tag includes them.
